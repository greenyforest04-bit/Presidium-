 🎨 PRESIDIUM UI/UX REDESIGN — ПРОМТ ДЛЯ ЛОКАЛЬНОГО АГЕНТА

## 📋 КОНТЕКСТ ПРОЕКТА

Ты работаешь над **Presidium** — децентрализованным P2P мессенджером на Python + PySide6 (Qt6). 
Стек: `asyncio`, `qasync`, `PySide6`, `aiosqlite`, `Pillow`.

Текущая проблема: UI функциональный, но выглядит "инженерно". Нужен **элитный минималистичный дизайн уровня Telegram iOS / iMessage macOS / Linear.app**.

---

## 🎯 ЦЕЛЬ

Полный редизайн интерфейса с сохранением всей бизнес-логики. Только UI-слой (`presidium/ui/`). 
НЕ трогай: `core/`, `db/`, `network/`, `messaging/` — только импортируй из них.

---

## 🏛 РЕФЕРЕНСЫ (запомни эти принципы)

| Принцип | Откуда | Как реализовать в PySide6 |
|---------|--------|---------------------------|
| **OLED Black** | Telegram iOS | `BG_PRIMARY = "#0F0F0F"` (не #000000, чтобы не смириться с OLED burn-in, но глубокий) |
| **Glassmorphism** | iMessage macOS | `QGraphicsBlurEffect(radius=20)` + `rgba(255,255,255,0.05)` overlay |
| **4px Grid** | Linear.app | Все отступы кратны 4: 4, 8, 12, 16, 24, 32, 48 |
| **Spring Animations** | Apple Design | `QEasingCurve.OutBack` для появления, `QPropertyAnimation` |
| **Material You** | Android | Accent color динамический (default `#6366F1`), но можно менять |
| **OLED Safe** | Modern apps | Чистый `#000000` как ОПЦИЯ в настройках (true black mode) |

from __future__ import annotations
from PySide6.QtCore import QPropertyAnimation, QEasingCurve, QPoint, QSize, QParallelAnimationGroup, QSequentialAnimationGroup
from PySide6.QtWidgets import QWidget
from typing import Optional


def fade_in(widget: QWidget, duration: int = 200, start: float = 0.0, end: float = 1.0) -> QPropertyAnimation:
    """Плавное появление через opacity."""
    widget.setWindowOpacity(start)
    anim = QPropertyAnimation(widget, b"windowOpacity")
    anim.setDuration(duration)
    anim.setStartValue(start)
    anim.setEndValue(end)
    anim.setEasingCurve(QEasingCurve.OutCubic)
    return anim


def slide_up(widget: QWidget, distance: int = 20, duration: int = 250) -> QPropertyAnimation:
    """Сдвиг снизу вверх с fade."""
    widget.move(widget.x(), widget.y() + distance)
    anim = QPropertyAnimation(widget, b"pos")
    anim.setDuration(duration)
    anim.setStartValue(QPoint(widget.x(), widget.y() + distance))
    anim.setEndValue(QPoint(widget.x(), widget.y()))
    anim.setEasingCurve(QEasingCurve.OutBack)
    return anim


def spring_scale(widget: QWidget, from_scale: float = 0.95, to_scale: float = 1.0, duration: int = 300) -> QPropertyAnimation:
    """Spring-анимация масштаба (как на iOS)."""
    # Для scale используем stylesheet transform или manual resize
    # Здесь — анимация geometry для простоты
    orig_size = widget.size()
    start_size = QSize(int(orig_size.width() * from_scale), int(orig_size.height() * from_scale))
    
    anim = QPropertyAnimation(widget, b"size")
    anim.setDuration(duration)
    anim.setStartValue(start_size)
    anim.setEndValue(orig_size)
    anim.setEasingCurve(QEasingCurve.OutBack)  # Spring!
    return anim

class GlassPanel(QWidget):
    """Frosted glass panel для context menus, modals, dropdowns."""
    
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setAttribute(Qt.WA_TranslucentBackground)
        self.setWindowFlags(Qt.FramelessWindowHint)
        
        # Blur effect
        self.blur = QGraphicsBlurEffect()
        self.blur.setBlurRadius(20)
        self.setGraphicsEffect(self.blur)
        
        # Border + bg
        self.setStyleSheet(f"""
            GlassPanel {{
                background-color: {TOKENS.GLASS_BG};
                border: 1px solid {TOKENS.GLASS_BORDER};
                border-radius: {RADIUS.MD}px;
            }}
        """)

class SwipeGestureRecognizer:
    """Распознавание свайпов для мобильного UI."""
    
    def __init__(self, widget: QWidget):
        self.widget = widget
        self.start_pos = None
        self.threshold = 80  # px
    
    def mousePressEvent(self, event):
        self.start_pos = event.pos()
    
    def mouseReleaseEvent(self, event):
        if not self.start_pos:
            return
        delta = event.pos().x() - self.start_pos.x()
        if abs(delta) > self.threshold:
            if delta > 0:
                self.on_swipe_right()
